# 005 README

## Goal

Write a README that explains what the repo is, why it exists, and how to run it.

## Context

This is the central REST API in a home automation and irrigation system. It talks to a MySQL database, an MQTT broker, and serves both a React Native mobile app and a React web app.

## Scope

Write README.md with these sections in order:
1. Title and one sentence summary
2. CI badge
3. Why I built it
4. How it fits (link related repos)
5. Stack
6. Running it locally
7. Configuration (table of env vars)
8. Tests
9. How I work on it

## Out of scope

- Screenshots (no UI in this repo)
- Architecture and Components sections (not the main repo of the project)

## Acceptance criteria

- README.md exists with all sections listed above
- CI badge at the top
- Env var table matches .env.example
- Links to related repos use GitHub URLs

## Test plan

- Read the README and confirm accuracy against the code
